# どっちに池袋

池袋から氷川台へ向かう利用者が、有楽町線・副都心線の列車候補を比較するスマートフォン向けWebアプリのUI試作です。

> **注意:** 表示される列車・時刻・接続はすべて架空です。実際の乗車判断には使用しないでください。

## 起動方法

`index.html` をブラウザーで開きます。ビルドやフレームワーク、外部ライブラリは不要です。

## ファイル構成

- `index.html`: 画面の骨組み
- `styles.css`: レスポンシブ表示とカードのスタイル
- `app.js`: 時計、候補表示、並び替え、直通フィルター
- `data.js`: 架空の列車・接続データ
- `docs/product_spec.md`: 製品目的・要件・ODPT移行課題
- `docs/ui_spec.md`: 現在の画面仕様
- `docs/devlog.md`: 開発履歴

詳細は `docs/` を参照してください。
