# UI仕様

この文書は、合意済みのUI詳細仕様の正本です。製品要件は product_spec.md、実装状況や確認待ちは project_state.md を参照してください。

## 画面の基本構成

1. アプリ名「どっちに池袋」と現在時刻（秒単位）
2. 架空ダイヤであり乗車判断に使えない旨の注意表示
3. 固定ルート「池袋 → 氷川台」と試作中の補助表示
4. 直通のみフィルターと「路線別｜発車順」の切替を同じ行に配置
5. 列車カード一覧
6. 時刻・接続が仮設定であることと未対応事項の注記
7. 画面下部の固定広告プレースホルダー

## ヘッダー・通知・目的地

- 装飾的な「MY TRAIN BOARD」見出しは置かない。アプリ名と時計を表示する。
- 架空ダイヤの注意書きは維持する。将来、運行情報・エラー等のアラート領域として再利用できるが、現在その機能はない。
- 目的地は「池袋 → 氷川台」を一行で表示する。駅選択へ拡張可能な領域とするが、現行UIに選択操作はない。
- 画面上部の余白を抑え、列車カードを表示する領域を広く確保する。

## 操作

- 直通フィルターは左、路線別／発車順切替は右に同じ行で配置する。
- 両操作の行は約44px高を確保する。切替ボタンは約38px高、チェックボックスは20px四方を目安とする。
- 375px、390px、430px幅を優先し、390px幅で横にはみ出さない。359px以下ではカード列幅と一部文字を控えめに縮小する。

## 列車カードと並び順

- カードの最小高は約68px。カードの表示情報や文字サイズは、読みやすさを保ちつつ現行レイアウトを維持する。
- カードには路線名、種別、行き先、発車時刻、秒単位カウントダウン、目的地到着時刻、直通／小竹向原乗換情報を表示する。
- 列車種別・行き先と接続情報は約14px、補助ラベルは約12px。カウントダウンは約23px、到着時刻は約15pxを基準にする。
- iPhone標準システムフォントを優先し、カウントダウンと時刻はタブラー数字を用いる。
- カウントダウンは毎秒更新し、発車まで3分以内は赤くする。
- デモ上の最早着候補にはマークを付ける。最早着マークは唯一の推奨を意味しない。
- 路線色バーはカード左端に9px幅で表示する。有楽町線は黄／ゴールド系 #c1a026、副都心線はブラウン #9C5E31。
- 路線別表示ではカード外の路線見出しを置かず、有楽町線を上、副都心線を下に並べる。同一路線内は発車時刻順。路線ごとの本数は先頭カードに表示し、路線グループ間は通常のカード間隔より広くする。
- 発車順表示では路線を混在させ、全候補を発車時刻順に並べる。
- デモ候補がなくなった場合は再読み込み案内を表示する。

## 広告プレースホルダー

- 実広告ではない320×50 CSS pxの枠を画面下部に固定表示する。背景 #D8E9F8、枠線 #3785C9、角丸4px、中央表示「AD 320×50」。
- 画面幅320px未満では左右24pxの余白内に縮小する。
- viewport metaは viewport-fit=cover。広告固定ドック内で safe-area-inset-bottom を一度だけ内側余白として扱う。本文側は広告本体・セーフエリア・20pxの間隔分の下余白を確保し、広告と注記・カードを重ねない。
- 広告SDK、外部ライブラリ、JavaScriptによるスクロール追従は使用しない。
- 6本と広告が初期画面内に収まることを目指すが、端末の表示領域に応じて縦スクロールを許容する。文字を無理に縮めて押し込まない。

## アクセシビリティ

切替ボタンは aria-pressed、候補領域は aria-live="off" を設定する。ボタンのキーボードフォーカスを可視化する。

## 未実装・制限

現在は架空の時刻・所要時間・接続であり、実乗車判断には使えない。目的地選択、データ更新時刻、平日／休日切替、運行情報・エラーアラート、実広告は未実装。最早着の計算も架空値に基づく。
