# UI仕様

## 基本方針

Ver.0.2試作の表示を維持し、スマートフォン縦画面を優先する。最大幅520pxの中央カラムで、列車情報をコンパクトに表示する。

## 画面構成

1. アプリ名と現在時刻（秒単位）
2. 架空ダイヤであり乗車判断に使えない旨の注意
3. 池袋から氷川台への固定ルート表示
4. 「直近の乗車候補」見出し、路線別／発車順切替
5. 直通のみフィルター
6. 路線ごとの列車カード一覧
7. 時刻・接続が仮設定であることと未対応事項の注記
8. 画面下部に固定した320×50相当の仮広告枠

## 列車カード

約68pxを最小高の目安に、左側に路線色バー、列車情報、発車までの残時間、氷川台到着時刻を並べる。iPhone縦画面で読みやすいシステムフォントを使い、列車種別・行先と直通／小竹向原乗換情報は14px程度、補助ラベルは12pxとする。発車情報と接続情報は必要に応じて折り返し、横方向にはみ出さないようにする。カウントダウンはタブラー数字を維持し、残り3分以内は赤くする。デモ上の最早着候補には印を付けるが、候補の比較を妨げない範囲に留める。

- 有楽町線: 黄系 `#c1a026`
- 副都心線: ブラウン `#9C5E31`

## 操作と更新

カウントダウンと時計を1秒ごとに更新する。路線別表示は副都心線、有楽町線の順。発車順表示は全候補を発車時刻順に並べる。直通フィルターは乗換を含む候補を隠す。候補がなくなると再読み込み案内を表示する。

## 画面幅とアクセシビリティ

375px、390px、430px幅のiPhone表示を優先し、359px以下ではカード列幅と一部文字を控えめに縮小する。上部余白を抑え、6本を一画面で確認できる密度を目指す。画面下部の仮広告枠はセーフエリア上に固定し、メイン領域の下余白で注記や列車カードと重ならないようにする。ボタンはキーボードのフォーカスを可視化し、表示順切替は `aria-pressed`、列車一覧は `aria-live="off"` を設定する。

## 仮広告枠

実広告ではない320×50 CSS pxのプレースホルダーを画面下部に固定表示する。背景は `#D8E9F8`、枠線は `#3785C9`、角丸は4pxとし、中央に「AD 320×50」と表示する。320px未満の画面では左右24pxの余白内に縮小する。固定コンテナが `safe-area-inset-bottom` を一度だけ内側余白として扱い、メイン領域は広告本体・safe-area・20pxの間隔分だけ下余白を確保する。`viewport-fit=cover` を使う。広告SDK・外部ライブラリやJavaScriptによる追従は使用しない。

## 現状の制限

目的地選択、データ更新時刻、平日／休日切替は未実装。現在の時刻表・所要時間・接続は架空で、最早着表示も架空値から計算している。遅延反映や接続保証はない。
