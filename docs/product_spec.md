# 製品仕様

## 目的

池袋駅を日常的に使う人が、目的地へ向かう複数列車の発車残時間、到着時刻、接続条件を一覧で比較し、自分で乗車列車を決められるようにする。

## 初期検証の範囲

- 出発駅: 池袋（固定）
- 目的地: 氷川台（固定）
- 比較対象: 東京メトロ有楽町線・副都心線
- 対象旅程: 直通列車、小竹向原で乗り換える列車
- 現段階では架空データを使用。実乗車判断には使えない旨を表示

## 開発方針

スマートフォン縦画面を優先し、列車情報をコンパクトに示す。有楽町線と副都心線の色を区別し、発車カウントダウン、到着時刻、小竹向原での接続情報を表示する。アプリが単一の最適解を押し付けず、候補を見比べる体験を重視する。機能・UIの追加は検証に必要な範囲に留める。

## 機能要件

1. 路線別表示と発車時刻順表示を切り替える。
2. 直通列車だけに絞り込める。
3. 各候補に発車時刻、秒単位カウントダウン、種別、行先、氷川台到着時刻を表示する。
4. 直通か小竹向原乗換か、乗換待ちの目安を表示する。
5. 架空データであることを画面に明記する。

## 到達可能性と候補提示

実データ移行後は池袋発列車ごとに目的地までの旅程を構成する。直通停車列車はその到着時刻を使う。小竹向原乗換は乗換先の発車時刻、ホーム間移動、必要な乗換時間を考慮する。接続条件が確かでない場合は接続可能と断定しない。日付跨ぎ、運行日、臨時ダイヤも扱う。候補の比較を保ち、最速候補を唯一の正解として扱わない。

## ODPT実データ移行時の技術課題

- **データの粒度:** 駅時刻表だけで目的地到着を計算できるか、列車ごとの停車駅・発着時刻まで取得できるかを確認する。
- **識別と対応付け:** 駅・路線・列車・便のID、事業者間直通列車の表現を確認し、路線名文字列に依存しない内部モデルへ変換する。
- **ダイヤ条件:** 平日／土休日、曜日、祝日、臨時・変更ダイヤの適用判定と日付跨ぎを実装する。
- **接続判定:** 小竹向原のホーム、乗換経路、移動時間、接続待ち、遅延時の接続保証の有無を確認する。データだけで保証できない場合は目安として示す。
- **リアルタイム性:** ODPTから取得できる遅延・運行情報、更新間隔、欠損時の扱いを調べ、時刻表ベースか遅延反映済みかを明示する。
- **利用条件:** 対象API・データセットの利用登録、商用可否、キャッシュ条件、表示義務、帰属表記を確認する。
- **認証と配信:** キーをブラウザーコードへ埋め込まない。必要ならサーバー側のプロキシ、秘密情報保管、レート制限、CORS対策を設計する。キー取得前にAPI接続は行わない。
- **障害と鮮度:** 通信失敗、古いキャッシュ、部分データを区別し、データ取得時刻と状態を利用者に示す。
- **検証:** 架空データの内部形式と実データ変換を分離し、停車・接続・運行日判定を実例と境界条件で検証する。

## 未確定事項
